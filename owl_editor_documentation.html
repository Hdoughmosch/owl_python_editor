💡 Tips & Tricks

🎯 Auto-Pair Brackets: Typing ( automatically inserts () with cursor inside. Same for [], {}, "", ''.
🖱️ Right-Click Menu: Right-click anywhere in the editor for quick access to Cut, Copy, Paste, Find, Run, and more.
📁 File Sidebar: Press F3 to show/hide the file explorer. Double-click any .py file to open it instantly.
🔍 Search in Files: Ctrl+Shift+F searches across ALL .py files in your current folder. Double-click results to jump to that line.
🎨 Theme Switching: Use the dropdown in the toolbar or View → Themes to switch between 10 beautiful color schemes instantly.
⚡ Module Scanner: Go to Tools → Scan Installed Modules to cache all your Python libraries for smarter autocomplete.
📐 JSON Formatting: Select messy JSON text and press Ctrl+Shift+J to instantly prettify it.
🧘 Zen Mode: Press F11 to enter distraction-free fullscreen mode. Only your code, nothing else.

🚀 Getting Started

  1. Download owl_python_editor.py
  2. Double-click to run (requires Python 3.7+)
  3. Or run from terminal: python owl_python_editor.py
  4. Start coding! No installation needed.

📦 Requirements

  • Python 3.7 or higher
  • tkinter (included with Python on Windows/macOS)
  • Linux: sudo apt-get install python3-tk
  • No pip install needed! Single file, zero dependencies.
