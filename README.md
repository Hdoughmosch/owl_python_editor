# 🦉 Owl Python Editor

**A lightweight, beautiful Python code editor that runs on anything.**

Built for coders who love speed, elegance, and zero bloat.

---

| Dependencies | Dozens or hundreds | **Zero — just Python** |
| File count | Thousands of files | **ONE file** |

## 🚀 Features

### 🎨 20 Beautiful Themes
Taqua 🥇 | Sail 🌊 | Sun ☀️ | Monokai 💚 | Dracula 🧛 | Nord ❄️ | Gruvbox 🟤 | One Dark 🔵 | Solarized 🌅 | Rose Pine 🌸

### ⚡ Pro Features
- 🌈 **Rainbow Brackets** — each nesting level gets its own color
- 🖱️ **Multiple Cursors** — Ctrl+Click to edit multiple lines at once
- 📁 **File Explorer Sidebar** — F3 toggle, double-click to open
- 🔍 **Search in Files** — Ctrl+Shift+F across all .py files
- 📌 **Bookmarks** — Ctrl+B mark, F2 jump between them
- 📂 **Code Folding** — collapse def/class/if blocks
- ⚡ **Code Snippets** — type `for` + Tab → full for loop
- 🔧 **Smart Auto-Complete** — keywords, builtins, installed packages
- 🎯 **Bracket Matching** — highlight pairs in real-time
- 📐 **Indentation Guides** — faint vertical lines show nesting
- ▶️ **Live Execution** — F5 run, clickable error lines
- 📋 **Output Panel** — copy output, jump to errors
- 🔄 **Auto-Save** — never lose work
- 🧘 **Zen Mode** — F11 fullscreen, only code
- 📄 **Recent Files** — last 10 files, one click
- 🖱️ **Drag & Drop** — drop .py files from Explorer

### 🛠️ Editing Power
- Syntax highlighting (7 token types)
- Line numbers + current line highlight
- Find & Replace with regex
- Go to Line (Ctrl+G)
- Word Wrap (Alt+Z)
- Zoom In/Out (Ctrl+MouseWheel)
- Toggle Comments (Ctrl+/)
- Duplicate Line (Ctrl+D)
- Auto-pair brackets & quotes
- Smart indent on Enter/Tab
- JSON Formatter (Ctrl+Shift+J)
- Right-click context menu

## 📥 Installation

**Requirements:** Python 3.7+

**Windows:**
```bash
python owl_python_editor.py
```

**macOS:**
```bash
python3 owl_python_editor.py
```

**Linux:**
```bash
sudo apt-get install python3-tk
python3 owl_python_editor.py
```

That's it. No pip. No dependencies. No setup.

## 📝 Code Snippets

Type the trigger, then press **Tab**:

| Trigger | Expands To |
|---------|-----------|
| `for` | `for item in iterable:` |
| `def` | `def name(args):` |
| `if` | `if condition:` |
| `ife` | `if condition: ... else: ...` |
| `main` | `if __name__ == "__main__":` |
| `try` | `try: ... except Exception as e: ...` |
| `with` | `with open(file, 'r') as f:` |
| `tk` | Full tkinter window template |
| `log` | Full logging setup |
| `list` | List comprehension |
| `dict` | Dict comprehension |
| `print` | `print(f"message")` |
| `imp` | `import module` |
| `from` | `from module import name` |
| `class` | Full class with constructor |
